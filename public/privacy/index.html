隐私政策Privacy

生效日期：Effective 2026-11-14

一句话：本站不收集、不保存、不出售你的个人数据。没有账号，没有 Cookie，没有广告，没有统计或追踪脚本。

本站在你的设备上保存什么

只有两项偏好：界面语言和亮/暗主题，保存在你浏览器的 localStorage 里，不会发送给任何人。清除浏览器的网站数据即可删除。

托管服务商会处理什么

本站是放在 Cloudflare 上的静态网页。为了把网页送到你的浏览器并防御攻击，Cloudflare 会处理每次访问的技术信息，例如 IP 地址、浏览器类型和访问时间，按 Cloudflare 隐私政策处理。维护者最多只能看到 Cloudflare 提供的汇总数字（例如每天的访问量），看不到具体是谁在访问。

字体和外部资源

本站使用的字体放在本站自己的服务器上，打开页面时不会连接 Google 或其他第三方。

游戏和外部链接

游戏不在本站运行，而是由各自作者的网站提供。你点「开始玩」时，游戏网站会在本页的播放窗口中加载；点「新标签打开」或任何外部链接时，你会直接访问那个网站。这些网站会收到你的 IP 地址等信息，可能使用 Cookie、账号或在线多人功能，适用它们自己的隐私政策。没点开之前，本站不会加载任何游戏网站。

儿童

本站不收集任何人的个人数据，包括儿童。部分游戏有在线多人或聊天功能，家长请留意孩子玩的是哪个游戏。

在 GitHub 上联系我们

如果你在 GitHub Issues 反馈问题，你发布的内容是公开的，适用 GitHub 的隐私政策。

变更

本政策如有修改，会更新本页的生效日期，修改记录可在代码仓库中查看。

In one line: this site does not collect, store or sell your personal data. There are no accounts, no cookies, no ads, and no analytics or tracking scripts.

What the site keeps on your device

Two preferences only: interface language and light or dark theme, kept in your browser's localStorage and never sent anywhere. Clearing this site's data in your browser deletes them.

What the hosting provider processes

This is a static website hosted on Cloudflare. To deliver pages and defend against attacks, Cloudflare processes technical data about each request, such as IP address, browser type and time, under the Cloudflare Privacy Policy. The maintainer can at most see aggregate numbers Cloudflare provides, such as visits per day, never who visited.

Fonts and outside resources

The fonts are served from this site itself. Opening a page makes no request to Google or any other third party.

Games and outside links

The games do not run on this site; their authors host them. When you press “Play here”, the game's site loads inside this page's player. When you open a game in a new tab or follow any outside link, you visit that site directly. Those sites receive your IP address and similar data, may use cookies, accounts or online multiplayer, and follow their own privacy policies. Until you open one, this site loads no game site at all.

Children

This site collects no personal data from anyone, children included. Some games have online multiplayer or chat; parents should check which game a child is playing.

Contacting us on GitHub

If you report something in GitHub Issues, what you post is public and GitHub's privacy policy applies.

Changes

If this policy changes, the effective date on this page changes with it, and the history is visible in the code repository.
